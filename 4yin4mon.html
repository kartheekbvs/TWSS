Programming Languages

In this course, we'll cover four popular programming languages: C, C++, Java, and Python. Each has its own strengths and use cases, but understanding the fundamentals across all of them will make you a versatile programmer.

C

A procedural programming language that provides low-level access to memory. It's efficient and widely used in system programming.

#include 

int main() {
    printf("Hello, World!");
    return 0;
}

C++ (Recommended)

An extension of C that adds object-oriented features. It's widely used for competitive programming and system/software development.

#include 

int main() {
    std::cout << "Hello, World!";
    return 0;
}

Java

A class-based, object-oriented language designed to have as few implementation dependencies as possible. It's "write once, run anywhere".

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Python

An interpreted, high-level, general-purpose programming language. Its design philosophy emphasizes code readability.

print("Hello, World!")

Language Recommendation

For serious DSA practice and competitive programming, C++ is highly recommended. It offers direct memory control and superior speed, which is crucial for performance-intensive algorithms. Mastering C++ first gives you an unparalleled understanding of efficiency.

Variables & Data Types

Variables are containers for storing data values. In programming, a variable is a named location in memory that stores a value. The type of data that can be stored in a variable is determined by its data type.

Common Data Types

Integer Whole numbers int int int
Floating Point Numbers with decimal points float, double float, double float
Character Single character char char str (length 1)
Boolean True or False values bool boolean bool
String Sequence of characters char[] or string String str

Functions

A function is a block of organized, reusable code that is used to perform a single, related action. Functions provide better modularity for your application and a high degree of code reusing.

Function Components

  • Function Name: A unique identifier for the function
  • Parameters: Input values passed to the function
  • Return Type: The type of value the function returns
  • Function Body: The code that executes when the function is called
  • Return Statement: Specifies the value to return from the function

Function Examples

C Language

// Function to add two numbers
int add(int a, int b) {
    return a + b;
}

// Function call
int result = add(5, 3); // result = 8

C++ Language

// Function to multiply two numbers
double multiply(double x, double y) {
    return x * y;
}

// Function call
double product = multiply(4.0, 2.5); // product = 10.0

Java Language

public static String greet(String name) {
    return "Hello, " + name + "!";
}

// Function call
String greeting = greet("Jane"); // greeting = "Hello, Jane!"

Python Language

# Function to calculate power
def power(base, exp):
    return base ** exp

# Function call
result = power(2, 4) # result = 16

Arrays

An array is a collection of items of the same data type stored at contiguous memory locations. Arrays are used to store multiple values in a single variable, instead of declaring separate variables for each value.

Key Characteristics of Arrays

Fixed Size

Arrays have a fixed size determined at creation. You cannot change the size of an array after it has been created.

Same Data Type

All elements in an array must be of the same data type. You cannot mix different types in a single array.

Index-Based Access

Elements in an array are accessed using their index, which starts at 0. The first element is at index 0, the second at index 1, and so on.

Contiguous Memory

Array elements are stored in contiguous memory locations, which allows for efficient access using pointer arithmetic.

Vectors

Vectors are dynamic arrays that can grow or shrink in size. Unlike arrays, vectors don't have a fixed size and can automatically resize themselves when elements are added or removed. This makes them more flexible for situations where the number of elements is not known in advance.

Advantages of Vectors over Arrays

Dynamic Size

Vectors can change their size dynamically, allowing you to add or remove elements as needed without worrying about fixed size limitations.

Ease of Use

Vectors provide convenient methods for adding, removing, and accessing elements, making them easier to use than traditional arrays.

Memory Management

Vectors handle their own memory management, automatically allocating more memory when needed and deallocating when elements are removed.

Built-in Functions

Vectors come with built-in functions for common operations like sorting, searching, and finding the size of the vector.

Vector Examples

C Language

// C doesn't have built-in vectors
// You need to implement dynamic arrays manually
// using malloc, realloc, and free

int *numbers = malloc(5 * sizeof(int));
// ... use realloc to resize ...
free(numbers);

C++ Language

// Vector declaration in C++
#include 
std::vector numbers;

// Adding elements
numbers.push_back(10); // [10]
numbers.push_back(20); // [10, 20]

// Accessing elements
int first = numbers[0]; // 10

// Size of vector
int size = numbers.size(); // 2

Java Language

// ArrayList in Java (similar to vectors)
import java.util.ArrayList;
ArrayList names = new ArrayList<>();

// Adding elements
names.add("Alice"); // ["Alice"]
names.add("Bob");   // ["Alice", "Bob"]

// Accessing elements
String first = names.get(0); // "Alice"

// Size of ArrayList
int size = names.size(); // 2

Python Language

# Python lists are dynamic by default
numbers = []

# Adding elements
numbers.append(10) # [10]
numbers.append(20) # [10, 20]

# Accessing elements
first = numbers[0] # 10

# Length of list
length = len(numbers) # 2

Strings

A string is a sequence of characters. In programming, strings are used to represent text. Different languages handle strings differently, but they all provide ways to create, manipulate, and access strings.

Common String Operations

Concatenation

Joining two or more strings together to form a new string. For example, "Hello" + "World" becomes "HelloWorld".

Substring

Extracting a portion of a string. For example, extracting "World" from "HelloWorld".

Length

Finding the number of characters in a string. For example, the length of "Hello" is 5.

Comparison

Comparing two strings to check if they are equal or which one comes first alphabetically.

String Examples

C Language

// Strings in C are character arrays

char str2[] = "World";
char result[20];

// Concatenation
strcpy(result, str1);
strcat(result, str2); // result = "HelloWorld"

// Length
int len = strlen(str1); // len = 5

// Concatenation

// Length

// Substring
std::string sub = str1.substr(1, 3); // "ell"

Java Language

// Concatenation

Control Flow

Control flow refers to the order in which the program's code executes. By default, code executes sequentially from top to bottom. Control flow statements allow you to change this order based on conditions or by repeating code multiple times.

Types of Control Flow Statements

Conditional Statements

These statements execute code based on whether a condition is true or false. Examples include if, if-else, and switch statements.

Looping Statements

These statements repeat a block of code multiple times. Examples include for, while, and do-while loops.

Branching Statements

These statements transfer control to another part of the program. Examples include break, continue, and goto (though goto is generally discouraged).

Exception Handling

These statements handle errors and exceptional conditions. Examples include try-catch blocks in Java and C++.

Conditional Statements Examples

C Language

// If-else statement in C
int age = 18;
if (age >= 18) {
    printf("You are eligible to vote.");
} else {
    printf("You are not eligible to vote.");
}

C++ Language

// Switch statement in C++
char grade = 'B';
switch (grade) {
    case 'A':
        cout << "Excellent!";
        break;
    case 'B':
        cout << "Good!";
        break;
    default:
        cout << "Invalid grade";
}

Looping Statements Examples

Java Language

// For loop in Java
for (int i = 1; i <= 5; i++) {
    System.out.println("Iteration: " + i);
}

// While loop in Java
int count = 0;
while (count < 3) {
    System.out.println("Count: " + count);
    count++;
}

Python Language

# For loop in Python

    print(f"Iteration: {i}")

# While loop in Python

Object-Oriented Programming (OOP) Basics

Object-Oriented Programming (OOP) is a programming paradigm based on the concept of "objects", which can contain data and code. The data is in the form of fields (often known as attributes or properties), and the code is in the form of procedures (often known as methods).

Core Principles of OOP

Encapsulation

Bundling the data (attributes) and methods that operate on the data into a single unit called a class. It also involves restricting direct access to some of an object's components.

Abstraction

Hiding the complex implementation details and showing only the necessary features of an object. This helps reduce complexity and increase efficiency.

Inheritance

Creating new classes from existing ones. The new class (subclass) inherits attributes and methods from the existing class (superclass), allowing for code reuse.

Polymorphism

The ability of an object to take on many forms. It allows methods to do different things based on the object that is acting upon them, often through method overriding.

Class and Object Examples

C++ Language

// Class definition in C++
class Student {
private:
    string name;

public:

    // Method
    void display() {
        cout << "Name: " << name << ", Age: " << age << endl;
    }
};

// Creating an object

Algorithm Complexity

Algorithm complexity is a measure of the amount of time and/or space required by an algorithm for an input of a given size. It helps us understand how an algorithm's performance will change as the input size grows.

Types of Complexity

Time Complexity

Measures the amount of time an algorithm takes to complete as a function of the length of its input. It's usually expressed using Big O notation.

Space Complexity

Measures the amount of memory space an algorithm needs to solve a problem. It's also expressed using Big O notation.

Common Complexity Classes

Notation Name Description Example Algorithms
O(1) Constant Execution time is constant regardless of input size Accessing an array element by index
O(log n) Logarithmic Execution time grows logarithmically with input size Binary search
O(n) Linear Execution time grows linearly with input size Linear search
O(n log n) Linearithmic Execution time grows as n multiplied by log n Merge sort, Quick sort
O(n²) Quadratic Execution time grows as the square of input size Bubble sort, Insertion sort
O(2ⁿ) Exponential Execution time grows exponentially with input size Brute-force algorithms

Complexity Comparison

Time Complexity Examples

O(1) - Constant Time

// Accessing an array element by index
int getElement(int[] arr, int index) {
    return arr[index];  // O(1) operation
}

O(n) - Linear Time

// Finding the maximum element in an array
int findMax(int[] arr) {
    int max = arr[0];
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;  // O(n) operation
}

Space Complexity Examples

O(1) - Constant Space

// Summing elements of an array
int sumArray(int[] arr) {
    int sum = 0;  // Constant space
    for (int i = 0; i < arr.length; i++) {
        sum += arr[i];
    }
    return sum;  // O(1) space complexity
}

O(n) - Linear Space

// Creating a copy of an array
int[] copyArray(int[] arr) {
    int[] copy = new int[arr.length];  // Linear space
    for (int i = 0; i < arr.length; i++) {
        copy[i] = arr[i];
    }
    return copy;  // O(n) space complexity
}

Data Structures & Algorithms

Data structures are ways of organizing and storing data so that it can be accessed and modified efficiently. Algorithms are step-by-step procedures for calculations or problem-solving operations. Together, they form the foundation of computer science and programming.

Common Data Structures

Arrays

A collection of items of the same data type stored at contiguous memory locations.

Time Complexity: Access O(1), Search O(n), Insertion O(n), Deletion O(n)

Linked Lists

A linear collection of data elements where each element points to the next.

Time Complexity: Access O(n), Search O(n), Insertion O(1), Deletion O(1)

Stacks

A LIFO (Last In First Out) data structure with operations: push and pop.

Time Complexity: Push O(1), Pop O(1), Peek O(1)

Queues

A FIFO (First In First Out) data structure with operations: enqueue and dequeue.

Time Complexity: Enqueue O(1), Dequeue O(1)

Trees

A hierarchical data structure with a root value and subtrees of children.

Time Complexity: Search O(log n) for balanced trees, O(n) for unbalanced

Graphs

A collection of nodes (vertices) connected by edges.

Time Complexity: Varies by operation and representation

Common Algorithms

Sorting Algorithms

  • Bubble Sort: O(n²)
  • Selection Sort: O(n²)
  • Insertion Sort: O(n²)
  • Merge Sort: O(n log n)
  • Quick Sort: O(n log n) average

Searching Algorithms

  • Linear Search: O(n)
  • Binary Search: O(log n)
  • Depth-First Search (DFS): O(V+E)
  • Breadth-First Search (BFS): O(V+E)

Binary Search Tree Example

// Node structure for a binary tree
struct TreeNode {
    int data;
    TreeNode* left;
    TreeNode* right;
};

// Inserting a node in a BST
TreeNode* insert(TreeNode* root, int data) {
    if (root == NULL) {
        TreeNode* newNode = new TreeNode();
        newNode->data = data;
        newNode->left = NULL;
        newNode->right = NULL;
        return newNode;
    }
    
    if (data < root->data) {
        root->left = insert(root->left, data);
    } else {
        root->right = insert(root->right, data);
    }
    
    return root;
}
