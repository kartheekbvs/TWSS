Cloud Deployment Models

Public Cloud

Resources owned and operated by third-party cloud service providers and delivered over the Internet.

Characteristics:

  • Multiple end users share resources
  • Connected via the internet
  • No deep technical knowledge required
  • Lower upfront costs

Example: Microsoft Azure

Private Cloud

Computing resources used exclusively by a single organization, which may be physically located at the organization's on-site datacenter.

Characteristics:

  • Organization manages all hardware
  • Resources used by single organization
  • Connected via private network
  • Requires deep technical knowledge

Use Case: Organizations with strict security requirements

Hybrid Cloud

Combines public and private clouds, bound together by technology that allows data and applications to be shared between them.

Characteristics:

  • Resources split between public and private
  • Cost efficiency from public cloud
  • Control from private cloud
  • Technical skills required for integration

Use Case: Organizations with sensitive data (e.g., medical records)
