Variables and Data Types

In Python, a variable is a named location used to store data in memory. Unlike some other programming languages, Python is dynamically typed, which means you don't need to declare the type of a variable explicitly.

Python has several built-in data types:

  • Integers (int): Whole numbers, e.g., 42, -10, 0
  • Floating-point numbers (float): Numbers with decimal points, e.g., 3.14, -0.001
  • Strings (str): Sequence of characters, e.g., "Hello", 'Python'
  • Booleans (bool): True or False values
  • Lists: Ordered collections of items, e.g., [1, 2, 3]
  • Dictionaries: Key-value pairs, e.g., {"name": "Alice", "age": 30}

Boolean Values and Operators

Boolean values represent truth values in Python. There are only two Boolean values: True and False. These values are often used in conditional statements to control the flow of a program.

Boolean operators are used to combine or modify Boolean values:

  • and: Returns True if both operands are True
  • or: Returns True if at least one operand is True
  • not: Returns the opposite of the operand

Comparison operators return Boolean values:

  • ==: Equal to
  • !=: Not equal to
  • >: Greater than
  • <: Less than
  • >=: Greater than or equal to
  • <=: Less than or equal to
# Boolean values

is_false = False

Break and Continue Statements

The break and continue statements allow you to control the flow of loops more precisely.

  • break: Terminates the loop prematurely
  • continue: Skips the rest of the current iteration and moves to the next one

These statements are useful when you need to exit a loop early under certain conditions or skip certain iterations.

# Using break in a loop
for item in sequence:
    if condition:
        break  # Exit the loop immediately

# Using continue in a loop
for item in sequence:
    if condition:
        continue  # Skip the rest of this iteration and continue with the next

Functions: Definition and Parameters

Functions are reusable blocks of code that perform a specific task. They help organize code, reduce repetition, and make programs more modular and easier to maintain.

In Python, functions are defined using the def keyword, followed by the function name and parentheses. Any input parameters are listed inside the parentheses.

Functions can have:

  • Parameters: Variables listed inside the parentheses in the function definition
  • Arguments: Values sent to the function when it is called
  • Return values: Values that the function sends back to the caller
# Function definition
def function_name(parameter1, parameter2):
    # Function body
    return result  # Optional return statement

# Function call
result = function_name(argument1, argument2)

Real-world Application

In data analysis, functions are used to perform repetitive calculations or data transformations. For example, you might create a function to calculate the compound interest for different investment scenarios, or a function to normalize data values.

# Function to calculate the mean of a list of numbers
def calculate_mean(numbers):
    if not numbers:  # Check if the list is empty
        return 0
    
    total = sum(numbers)
    count = len(numbers)
    return total / count

def calculate_median(numbers):
    if not numbers:
        return 0
    
    sorted_numbers = sorted(numbers)
    count = len(sorted_numbers)
    
    if count % 2 == 0:  # Even number of elements
        middle1 = sorted_numbers[count // 2 - 1]
        middle2 = sorted_numbers[count // 2]
        return (middle1 + middle2) / 2
    else:  # Odd number of elements
        return sorted_numbers[count // 2]

    return filtered_data

Function Scope and Return Values

Scope refers to the visibility of variables in different parts of the code. In Python, variables defined inside a function have local scope, meaning they are only accessible within that function. Variables defined outside all functions have global scope.

Functions can return values using the return statement. A function can return multiple values by separating them with commas, which Python will pack into a tuple.

Understanding scope is crucial for avoiding bugs and managing data flow in your programs.

# Local and global scope
global_var = 10  # Global variable

def function_with_scope():
    local_var = 20  # Local variable
    print(global_var)  # Can access global variable
    # print(local_var)  # This would cause an error outside the function

# Function with multiple return values
def calculate_stats(numbers):
    if not numbers:
        return 0, 0, 0, 0  # Return zeros for empty list
    
    total = sum(numbers)
    count = len(numbers)
    mean = total / count
    maximum = max(numbers)
    
    return total, mean, maximum, count  # Return multiple values

Function Composition and Recursion

Function composition is the process of combining functions to create more complex functions. In Python, you can pass functions as arguments to other functions, return functions from functions, and store functions in data structures.

Recursion is a technique where a function calls itself to solve a problem. Recursive functions have a base case that stops the recursion and a recursive case that brings the problem closer to the base case.

Both concepts are powerful tools for solving complex problems in a clean and elegant way.

# Function composition
def compose(f, g):
    return lambda x: f(g(x))

# Recursive function
def factorial(n):
    # Base case
    if n <= 1:
        return 1
    # Recursive case
    else:
        return n * factorial(n - 1)

Real-world Application

In data analysis, function composition is used to create data processing pipelines, where each function performs a specific transformation on the data. Recursion is useful for processing hierarchical data structures, such as file systems or nested JSON objects.

# Example: Function composition and recursion in data analysis
# Function composition example
def apply_discount(price, rate):
    return price * (1 - rate)

def apply_tax(price, rate):
    return price * (1 + rate)

def format_currency(amount):
    return f"${amount:.2f}"

# Compose functions to create a pipeline

    # Apply discount, then tax, then format
    discounted_price = apply_discount(price, discount_rate)
    final_price = apply_tax(discounted_price, tax_rate)
    return format_currency(final_price)

    total = node["value"]

Errors and Exceptions

Exceptions are unexpected events that occur during program execution. Python's exception handling allows you to gracefully handle these situations.

Common types of exceptions include:

  • IOError: File input/output errors
  • ValueError: Invalid value for operation
  • KeyError: Dictionary key not found
  • IndexError: List index out of range
  • TypeError: Operation on incompatible type
  • ZeroDivisionError: Division by zero

Exception handling uses try-except-else blocks and can catch specific exception types.

# Exception handling
try:
    # Code that might raise an exception
    result = risky_operation()
except ValueError as e:
    print(f"ValueError occurred: {e}")
except TypeError as e:
    print(f"TypeError occurred: {e}")
except Exception as e:
    print(f"Unexpected error: {e}")
else:
    print("Operation completed successfully")

# Multiple except blocks
try:
    result = operation1()
except (ValueError, IndexError) as e:
    print(f"Data error: {e}")
    result = operation2()  # Fallback operation
except Exception as e:
    print(f"General error: {e}")

# Finally block
try:
    file = open('data.txt', 'r')
    data = file.read()
finally:
    file.close()  # Always executed

import json

class DataProcessor:
    def __init__(self, data_file):
        self.data_file = data_file
        self.data = []
        self.load_data()
    
    def load_data(self):
        """Load data from file with exception handling"""
        try:
            if os.path.exists(self.data_file):
                with open(self.data_file, 'r') as file:
                    for line in file:
                        if line.strip():
                            try:
                                item = json.loads(line)
                                self.data.append(item)
                            except json.JSONDecodeError:
                                print(f"Warning: Invalid JSON in line: {line}")
            else:
                print(f"Data file {self.data_file} not found. Starting with empty data.")
        except IOError as e:
            print(f"Error loading data file: {e}")
            raise
    
    def save_data(self, output_file):
        """Save data to file with exception handling"""
        try:
            # Ensure output directory exists
            output_path = Path(output_file)
            output_path.parent.mkdir(parents=True, exist_ok=True)
            
            with open(output_path, 'w') as file:
                for item in self.data:
                    json.dump(item, file)
                    file.write('\n')
            
            print(f"Data saved to {output_path}")
        except IOError as e:
            print(f"Error saving data: {e}")
            raise
    
    def get_statistics(self):
        """Calculate statistics with exception handling"""
        if not self.data:
            return {"error": "No data available"}
        
        try:
            total_items = len(self.data)
            if total_items == 0:
                return {"error": "Empty dataset"}
            
            # Calculate various statistics
            numeric_fields = []
            for item in self.data:
                for key, value in item.items():
                    if isinstance(value, (int, float)):
                        numeric_fields.append(value)
            
            if not numeric_fields:
                return {"error": "No numeric data found"}
            
            return {
                "total_items": total_items,
                "sum": sum(numeric_fields),
                "average": sum(numeric_fields) / len(numeric_fields),
                "min": min(numeric_fields),
                "max": max(numeric_fields)
            }
        except Exception as e:
            return {"error": f"Calculation error: {e}"}
    
    def process_with_retry(self, max_retries=3):
        """Process data with retry mechanism"""
        for attempt in range(max_retries):
            try:
                stats = self.get_statistics()
                if "error" not in stats:
                    print(f"Attempt {attempt + 1}: {stats}")
                    return stats
            except Exception as e:
                print(f"Attempt {attempt + 1} failed: {e}")
                if attempt == max_retries - 1:
                    raise  # Re-raise the exception after max retries
