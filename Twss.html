Course Units

Our Python programming course is structured into five comprehensive units covering everything from basics to advanced concepts

Unit I: Introduction

  • Introduction to Python and installation
  • Data types: Int, float, Boolean, string, List
  • Variables and expressions
  • Statements and operator precedence
  • Comments and modules
  • Functions: parameters and arguments

Unit II: Control Flow

  • Boolean values and operators
  • Conditional statements (if, if-else)
  • Chained conditionals (if-elif-else)
  • Iteration with while loops
  • For loops and iteration
  • Break and continue statements

Unit III: Functions & Arrays

  • Fruitful functions and return values
  • Parameters and scope (local/global)
  • Function composition and recursion
  • Strings: slices and immutability
  • String functions and methods
  • Python arrays and methods

Unit IV: Data Structures

  • Lists: operations and methods
  • List slices and loops
  • Mutability, aliasing, cloning
  • List parameters and comprehension
  • Tuples: assignment and return values
  • Dictionaries: operations and methods

Unit V: Files & Exceptions

  • Text files: reading and writing
  • Command line arguments
  • Errors and exceptions
  • Handling exceptions
  • Modules: datetime, time, OS, etc.
  • Exploring packages
