Function Basics

Functions are the building blocks of JavaScript. They allow you to group code together and reuse it multiple times. Functions can be declared in several ways:

// Function Declaration function greet(name) { return `Hello, ${name}!`; } // Function with parameters function add(a, b) { return a + b; } // Calling functions console.log(greet("World")); // Hello, World! console.log(add(5, 3)); // 8 // Function with default parameters function multiply(a, b = 1) { return a * b; } console.log(multiply(5)); // 5 console.log(multiply(5, 3)); // 15
Note: Function declarations are hoisted, meaning they can be called before they are defined in the code.

Functions can also return other functions, which is a powerful pattern in JavaScript:

function createMultiplier(multiplier) { return function(number) { return number * multiplier; }; } const double = createMultiplier(2); const triple = createMultiplier(3); console.log(double(5)); // 10 console.log(triple(5)); // 15
Example: This pattern is useful for creating specialized functions. The createMultiplier function returns a new function that multiplies its argument by the specified multiplier.

Functions can also have rest parameters, which allow you to represent an indefinite number of arguments as an array:

function sum(...numbers) { let result = 0; for (const num of numbers) { result += num; } return result; } console.log(sum(1, 2, 3)); // 6 console.log(sum(1, 2, 3, 4, 5)); // 15

Function Expressions

Function expressions allow you to define functions as part of larger expressions. They can be anonymous or named:

// Anonymous function expression const add = function(a, b) { return a + b; }; console.log(add(3, 4)); // 7 // Named function expression const factorial = function fact(n) { return n <= 1 ? 1 : n * fact(n - 1); }; console.log(factorial(5)); // 120 // Function expressions can be used as arguments function calculate(a, b, operation) { return operation(a, b); } console.log(calculate(10, 5, add)); // 15 console.log(calculate(10, 5, function(a, b) { return a - b; })); // 5
Note: Unlike function declarations, function expressions are not hoisted. They can only be used after they are defined.

Function expressions are commonly used for:

  • Callback functions
  • Immediately Invoked Function Expressions (IIFEs)
  • Assigning functions to object properties
// IIFE example (function() { console.log("This function runs immediately!"); const privateVar = "I'm private"; console.log(privateVar); // I'm private })(); // console.log(privateVar); // Error: privateVar is not defined // Assigning functions to object properties const calculator = { add: function(a, b) { return a + b; }, subtract: function(a, b) { return a - b; } }; console.log(calculator.add(5, 3)); // 8 console.log(calculator.subtract(5, 3)); // 2
Example: IIFEs are useful for creating a private scope and avoiding polluting the global namespace. They run immediately after being defined.

Arrow Functions

Arrow functions provide a more concise syntax for writing function expressions. They don't have their own 'this' context:

// Basic arrow function const add = (a, b) => a + b; console.log(add(5, 3)); // 8 // Arrow function with multiple statements const multiply = (a, b) => { const result = a * b; return result; }; console.log(multiply(4, 5)); // 20 // Arrow function with single parameter (no parentheses needed) const square = x => x * x; console.log(square(4)); // 16 // Arrow function with no parameters const getRandom = () => Math.random(); console.log(getRandom());
Note: Arrow functions do not have their own this, arguments, super, or new.target. They are well-suited for non-method functions.

The key difference between arrow functions and regular functions is how they handle this:

// Regular function - 'this' refers to global object function Counter() { this.count = 0; setInterval(function() { console.log("Regular function:", this.count); // undefined this.count++; // This increments the global count, not the Counter's count }, 1000); } // Arrow function - 'this' refers to Counter object function CounterArrow() { this.count = 0; setInterval(() => { console.log("Arrow function:", this.count); // 0, 1, 2, ... this.count++; // This increments the Counter's count }, 1000); } // const counter = new Counter(); // Would log undefined repeatedly // const counterArrow = new CounterArrow(); // Would log 0, 1, 2, ...
Example: Arrow functions are particularly useful when you need to preserve the this value from the enclosing scope, such as in callbacks or event handlers.

Arrow functions also have different behavior when returning objects:

// To return an object literal, wrap it in parentheses const createUser = (name, age) => ({ name, age }); const user = createUser("John", 30); console.log(user); // { name: "John", age: 30 } // Without parentheses, it's interpreted as a function body const brokenCreateUser = (name, age) => { name, age }; console.log(brokenCreateUser("John", 30)); // undefined

Advanced Functions

Explore closures, recursion, binding, and other advanced function patterns:

Closures

A closure is a function that has access to variables in its outer (enclosing) lexical scope even after the outer function has returned:

function createCounter() { let count = 0; return { increment: function() { count++; return count; }, decrement: function() { count--; return count; }, getCount: function() { return count; } }; } const counter = createCounter(); console.log(counter.increment()); // 1 console.log(counter.increment()); // 2 console.log(counter.decrement()); // 1 console.log(counter.getCount()); // 1
Note: Closures are commonly used for data privacy and creating function factories. The count variable is private and can only be accessed through the returned methods.

Recursion

A recursive function is a function that calls itself until it reaches a base case:

function factorial(n) { if (n <= 1) return 1; // Base case return n * factorial(n - 1); // Recursive case } console.log(factorial(5)); // 120 // Another example: Fibonacci sequence function fibonacci(n) { if (n <= 1) return n; return fibonacci(n - 1) + fibonacci(n - 2); } console.log(fibonacci(7)); // 13

Function Binding

The bind() method creates a new function that, when called, has its this keyword set to the provided value:

const person = { name: "John", greet: function() { console.log(`Hello, my name is ${this.name}`); } }; const greet = person.greet; // greet(); // Error: this.name is undefined const boundGreet = person.greet.bind(person); boundGreet(); // Hello, my name is John // Partial function application function multiply(a, b) { return a * b; } const double = multiply.bind(null, 2); console.log(double(5)); // 10 console.log(double(10)); // 20

Call and Apply

The call() and apply() methods call a function with a given this value and arguments:

function introduce(greeting, punctuation) { console.log(`${greeting}, my name is ${this.name}${punctuation}`); } const person = { name: "John" }; introduce.call(person, "Hi", "!"); // Hi, my name is John! introduce.apply(person, ["Hello", "."]); // Hello, my name is John. // Using apply with arrays const numbers = [5, 6, 2, 3, 7]; const max = Math.max.apply(null, numbers); console.log(max); // 7
Example: call() accepts arguments individually, while apply() accepts arguments as an array. Both are useful for borrowing methods from other objects.

Promises

Promises represent the eventual completion (or failure) of an asynchronous operation. They have three states: pending, fulfilled, or rejected:

// Creating a promise const promise = new Promise((resolve, reject) => { // Asynchronous operation setTimeout(() => { const success = true; // Simulate success or failure if (success) { resolve("Operation completed successfully!"); } else { reject("Operation failed!"); } }, 1000); }); // Consuming a promise promise .then(result => { console.log("Success:", result); }) .catch(error => { console.log("Error:", error); }) .finally(() => { console.log("Promise settled (finally block)"); });
Note: The finally() method is called regardless of whether the promise is fulfilled or rejected. It's useful for cleanup operations.

Promises can be chained to perform sequential asynchronous operations:

function fetchData() { return new Promise(resolve => { setTimeout(() => resolve("Data fetched"), 1000); }); } function processData(data) { return new Promise(resolve => { setTimeout(() => resolve(`${data} and processed`), 1000); }); } function saveData(data) { return new Promise(resolve => { setTimeout(() => resolve(`${data} and saved`), 1000); }); } fetchData() .then(processData) .then(saveData) .then(result => console.log(result)) .catch(error => console.error("Error:", error));

You can also work with multiple promises using Promise.all() and Promise.race():

// Promise.all - Wait for all promises to resolve const promise1 = Promise.resolve(3); const promise2 = new Promise(resolve => setTimeout(() => resolve("foo"), 1000)); const promise3 = fetch("https://jsonplaceholder.typicode.com/todos/1"); Promise.all([promise1, promise2, promise3]) .then(values => console.log("All promises resolved:", values)) .catch(error => console.error("At least one promise rejected:", error)); // Promise.race - Wait for the first promise to settle const promise4 = new Promise(resolve => setTimeout(() => resolve("First"), 500)); const promise5 = new Promise(resolve => setTimeout(() => resolve("Second"), 1000)); Promise.race([promise4, promise5]) .then(value => console.log("First promise settled:", value)) // "First" .catch(error => console.error("Error:", error));
Example: Promise.all() is useful when you need to wait for multiple asynchronous operations to complete before proceeding. Promise.race() is useful when you want to proceed as soon as the first operation completes.

Async/Await

Async/await is built on top of promises and provides a cleaner way to write asynchronous code:

// Async function always returns a promise async function hello() { return "Hello World!"; } hello().then(console.log); // Hello World! // Using await with promises function resolveAfter2Seconds() { return new Promise(resolve => { setTimeout(() => resolve("Resolved after 2 seconds"), 2000); }); } async function asyncCall() { console.log("Calling..."); const result = await resolveAfter2Seconds(); console.log(result); // This will run after 2 seconds } asyncCall();
Note: The await keyword can only be used inside an async function. It pauses the execution of the async function until the promise is settled.

Error handling with async/await is done using try/catch blocks:

async function fetchDataWithErrorHandling() { try { const response = await fetch("https://jsonplaceholder.typicode.com/todos/1"); const data = await response.json(); console.log(data); } catch (error) { console.error("Fetch error:", error); } } fetchDataWithErrorHandling();

You can also execute promises in parallel with async/await:

async function parallelExecution() { // Start both promises concurrently const promise1 = fetch("https://jsonplaceholder.typicode.com/todos/1"); const promise2 = fetch("https://jsonplaceholder.typicode.com/todos/2"); // Wait for both to complete const [response1, response2] = await Promise.all([promise1, promise2]); // Process the results const data1 = await response1.json(); const data2 = await response2.json(); console.log("Data 1:", data1); console.log("Data 2:", data2); } parallelExecution();

Async/await also works with promise chains:

async function promiseChain() { const result1 = await new Promise(resolve => setTimeout(() => resolve("Step 1"), 1000) ); console.log(result1); const result2 = await new Promise(resolve => setTimeout(() => resolve(`${result1} -> Step 2`), 1000) ); console.log(result2); const result3 = await new Promise(resolve => setTimeout(() => resolve(`${result2} -> Step 3`), 1000) ); console.log(result3); return result3; } promiseChain().then(result => console.log("Final result:", result));
Example: Async/await makes asynchronous code look and behave like synchronous code, making it easier to read and debug. However, it's important to remember that it doesn't block the main thread.

Fetch API

The Fetch API provides a modern interface for making network requests. It returns promises:

// Basic GET request fetch("https://jsonplaceholder.typicode.com/todos/1") .then(response => { if (!response.ok) { throw new Error("Network response was not ok"); } return response.json(); }) .then(data => console.log("Todo item:", data)) .catch(error => console.error("Fetch error:", error));
Note: The Fetch API doesn't reject on HTTP error status (like 404 or 500). You need to check the response.ok property or response.status to handle errors.

POST request with JSON data:

const newTodo = { title: "Learn JavaScript", completed: false, userId: 1 }; fetch("https://jsonplaceholder.typicode.com/todos", { method: "POST", headers: { "Content-Type": "application/json", }, body: JSON.stringify(newTodo) }) .then(response => response.json()) .then(data => console.log("Created todo:", data)) .catch(error => console.error("Error creating todo:", error));

PUT request to update data:

const updatedTodo = { id: 1, title: "Updated Todo", completed: true, userId: 1 }; fetch("https://jsonplaceholder.typicode.com/todos/1", { method: "PUT", headers: { "Content-Type": "application/json", }, body: JSON.stringify(updatedTodo) }) .then(response => response.json()) .then(data => console.log("Updated todo:", data)) .catch(error => console.error("Error updating todo:", error));

DELETE request:

fetch("https://jsonplaceholder.typicode.com/todos/1", { method: "DELETE" }) .then(response => { if (response.ok) { console.log("Todo deleted successfully"); } }) .catch(error => console.error("Error deleting todo:", error));

Using async/await with the Fetch API:

async function fetchTodo(id) { try { const response = await fetch(`https://jsonplaceholder.typicode.com/todos/${id}`); if (!response.ok) { throw new Error(`HTTP error! status: ${response.status}`); } const todo = await response.json(); console.log("Todo:", todo); return todo; } catch (error) { console.error("Could not fetch todo:", error); } } fetchTodo(1);
Example: The Fetch API is more powerful and flexible than the older XMLHttpRequest. It provides a cleaner, promise-based API for making network requests.

Network Requests

Explore different methods for making network requests, including XHR and WebSocket:

XMLHttpRequest (XHR)

XHR is an older API for making HTTP requests, but it's still widely used:

const xhr = new XMLHttpRequest(); xhr.open("GET", "https://jsonplaceholder.typicode.com/todos/1"); xhr.responseType = "json"; xhr.onload = function() { if (xhr.status >= 200 && xhr.status < 300) { console.log("XHR Response:", xhr.response); } else { console.error("XHR Error:", xhr.statusText); } }; xhr.onerror = function() { console.error("XHR Request failed"); }; xhr.send();

WebSocket

WebSockets provide a persistent connection between a client and server, allowing for real-time communication:

function createWebSocketConnection() { const socket = new WebSocket("wss://echo.websocket.org/"); socket.onopen = function(event) { console.log("WebSocket connection established"); socket.send("Hello WebSocket Server!"); }; socket.onmessage = function(event) { console.log("Message from server:", event.data); }; socket.onclose = function(event) { if (event.wasClean) { console.log(`WebSocket connection closed cleanly, code=${event.code}, reason=${event.reason}`); } else { console.error("WebSocket connection died"); } }; socket.onerror = function(error) { console.error("WebSocket Error:", error); }; // Close connection after 5 seconds setTimeout(() => { socket.close(); }, 5000); } // Uncomment to test WebSocket // createWebSocketConnection();
Note: WebSockets are ideal for real-time applications like chat apps, live updates, and collaborative tools. They maintain a persistent connection, allowing both client and server to send messages at any time.

AbortController

The AbortController API allows you to abort fetch requests when they're no longer needed:

const controller = new AbortController(); const signal = controller.signal; fetch("https://jsonplaceholder.typicode.com/todos/1", { signal }) .then(response => response.json()) .then(data => console.log("Fetch with AbortController:", data)) .catch(err => { if (err.name === "AbortError") { console.log("Fetch aborted"); } else { console.error("Fetch error:", err); } }); // Cancel the request after 100ms setTimeout(() => controller.abort(), 100);

Server-Sent Events (SSE)

SSE is a server-push technology that enables a client to receive automatic updates from a server via an HTTP connection:

function setupEventSource() { const eventSource = new EventSource("https://sse-demo.herokuapp.com/"); eventSource.onmessage = function(event) { console.log("New message:", event.data); }; eventSource.onerror = function(err) { console.error("EventSource failed:", err); eventSource.close(); }; // Close after 10 seconds setTimeout(() => { eventSource.close(); console.log("EventSource closed"); }, 10000); } // Uncomment to test SSE // setupEventSource();
Example: While WebSockets allow for bidirectional communication, SSE is designed for server-to-client communication. It's simpler to implement and works over standard HTTP.

DOM Structure

The Document Object Model (DOM) represents the structure of HTML documents as a tree of objects:

// The DOM tree structure /* Document └── html ├── head │ ├── title │ ├── meta │ └── link └── body ├── header │ ├── h1 │ └── nav │ └── ul │ └── li ├── main │ ├── section │ │ ├── h2 │ │ └── p │ └── section │ ├── h2 │ └── div └── footer └── p */
Note: The DOM is a programming interface for HTML documents. It represents the page so that programs can change the document structure, style, and content.

You can create and manipulate DOM elements using JavaScript:

// Create a sample DOM structure const container = document.createElement("div"); container.id = "container"; container.style.padding = "20px"; container.style.border = "1px solid #333"; container.style.marginBottom = "20px"; const heading = document.createElement("h1"); heading.textContent = "DOM Structure Example"; heading.style.color = "#00d4ff"; const paragraph = document.createElement("p"); paragraph.textContent = "This is a paragraph created with JavaScript."; paragraph.style.marginTop = "10px"; const list = document.createElement("ul"); list.style.listStyleType = "none"; list.style.padding = "0"; const items = ["Item 1", "Item 2", "Item 3"]; items.forEach(itemText => { const item = document.createElement("li"); item.textContent = itemText; item.style.padding = "5px 0"; item.style.borderBottom = "1px solid #444"; list.appendChild(item); }); container.appendChild(heading); container.appendChild(paragraph); container.appendChild(list); // Add to the page document.body.appendChild(container);

DOM tree navigation:

// Accessing DOM nodes console.log("Document element:", document.documentElement); console.log("Body element:", document.body); console.log("Head element:", document.head); // Node relationships console.log("Root element:", document.documentElement); console.log("Root children:", document.documentElement.childNodes); console.log("Body parent node:", document.body.parentNode); console.log("Body previous sibling:", document.body.previousSibling); console.log("Body next sibling:", document.body.nextSibling); // Element relationships (only element nodes) console.log("Body first element child:", document.body.firstElementChild); console.log("Body last element child:", document.body.lastElementChild); console.log("Body children:", document.body.children); console.log("Body previous element sibling:", document.body.previousElementSibling); console.log("Body next element sibling:", document.body.nextElementSibling);
Example: The DOM tree consists of different types of nodes, including element nodes, text nodes, attribute nodes, and more. When navigating the DOM, it's important to distinguish between all nodes (including text and comment nodes) and just element nodes.

Element Selection

JavaScript provides several methods to select and manipulate DOM elements:

// getElementById - Returns a single element const mainTitle = document.getElementById("main-title"); if (mainTitle) { mainTitle.style.color = "#00d4ff"; } // getElementsByClassName - Returns a live HTMLCollection const paragraphs = document.getElementsByClassName("intro"); for (let i = 0; i < paragraphs.length; i++) { paragraphs[i].style.backgroundColor = "#1a1a1a"; } // getElementsByTagName - Returns a live HTMLCollection const listItems = document.getElementsByTagName("li"); for (let i = 0; i < listItems.length; i++) { listItems[i].style.padding = "5px 0"; } // querySelector - Returns the first matching element const firstButton = document.querySelector("button"); if (firstButton) { firstButton.style.backgroundColor = "#00d4ff"; firstButton.style.color = "#000"; } // querySelectorAll - Returns a static NodeList const allLinks = document.querySelectorAll("a"); allLinks.forEach(link => { link.style.textDecoration = "none"; link.style.color = "#00d4ff"; });
Note: getElementsByClassName and getElementsByTagName return live collections that update automatically when the DOM changes. querySelectorAll returns a static collection that doesn't update.

You can also use more complex selectors with querySelector and querySelectorAll:

// Select elements by attribute const dataElements = document.querySelectorAll("[data-id]"); dataElements.forEach(element => { console.log("Element with data-id:", element); }); // Select elements by class and tag const specialDivs = document.querySelectorAll("div.special"); specialDivs.forEach(div => { div.style.border = "1px solid #00d4ff"; }); // Select elements with complex selectors const firstParagraphInSection = document.querySelector("section > p:first-child"); if (firstParagraphInSection) { firstParagraphInSection.style.fontWeight = "bold"; } // Select elements by pseudo-class const checkedInputs = document.querySelectorAll("input:checked"); checkedInputs.forEach(input => { console.log("Checked input:", input); });

Once you've selected elements, you can manipulate them:

// Get an element const box = document.querySelector(".box"); // Change content box.textContent = "New content"; box.innerHTML = "Bold content"; // Change attributes box.id = "new-id"; box.className = "new-class another-class"; box.setAttribute("data-info", "some data"); // Change styles box.style.color = "#00d4ff"; box.style.backgroundColor = "#1a1a1a"; box.style.padding = "10px"; box.style.borderRadius = "5px"; // Add/remove/toggle classes box.classList.add("highlight"); box.classList.remove("old-class"); box.classList.toggle("active"); // Check if class exists if (box.classList.contains("active")) { console.log("Box is active"); } // Create and insert new elements const newParagraph = document.createElement("p"); newParagraph.textContent = "This is a new paragraph"; newParagraph.className = "new-paragraph"; // Insert as last child box.appendChild(newParagraph); // Insert before an element const referenceElement = box.querySelector("p"); box.insertBefore(newParagraph, referenceElement); // Replace an element const oldElement = box.querySelector("span"); if (oldElement) { box.replaceChild(newParagraph, oldElement); } // Remove an element const elementToRemove = box.querySelector(".remove-me"); if (elementToRemove) { box.removeChild(elementToRemove); }
Example: When manipulating the DOM, it's often more efficient to make multiple changes to elements that are detached from the DOM, then reattach them. This reduces the number of reflows and repaints, improving performance.

Event Handling

Events are actions that occur as a result of user interaction or system events. JavaScript can respond to these events:

// Adding event listeners const button = document.querySelector("#my-button"); // Method 1: addEventListener button.addEventListener("click", function() { console.log("Button clicked!"); this.style.backgroundColor = "#00d4ff"; }); // Method 2: onclick property button.onclick = function() { console.log("Button clicked with onclick!"); }; // Method 3: HTML attribute (not recommended) // // function handleClick() { // console.log("Button clicked with HTML attribute!"); // }
Note: Using addEventListener is the recommended approach because it allows you to add multiple event listeners to the same event and provides more control over the event handling process.

Common event types:

// Mouse events element.addEventListener("click", handleClick); element.addEventListener("dblclick", handleDoubleClick); element.addEventListener("mousedown", handleMouseDown); element.addEventListener("mouseup", handleMouseUp); element.addEventListener("mouseover", handleMouseOver); element.addEventListener("mouseout", handleMouseOut); element.addEventListener("mousemove", handleMouseMove); // Keyboard events element.addEventListener("keydown", handleKeyDown); element.addEventListener("keyup", handleKeyUp); element.addEventListener("keypress", handleKeyPress); // Form events element.addEventListener("submit", handleSubmit); element.addEventListener("change", handleChange); element.addEventListener("input", handleInput); element.addEventListener("focus", handleFocus); element.addEventListener("blur", handleBlur); // Window events window.addEventListener("load", handleLoad); window.addEventListener("resize", handleResize); window.addEventListener("scroll", handleScroll);

The event object contains information about the event:

function handleClick(event) { // Prevent default behavior event.preventDefault(); // Stop event propagation event.stopPropagation(); // Event target console.log("Event target:", event.target); // Event type console.log("Event type:", event.type); // Mouse events console.log("Mouse position:", event.clientX, event.clientY); console.log("Button clicked:", event.button); // Keyboard events console.log("Key pressed:", event.key); console.log("Key code:", event.keyCode); // Form events console.log("Form data:", new FormData(event.target)); }

Event propagation and delegation:

// Event propagation (bubbling and capturing) /* When an event occurs on an element, it first runs the handlers on it, then on its parent, then all the way up on other ancestors. Capturing phase: Event goes down to the element. Target phase: Event reaches the target. Bubbling phase: Event bubbles up from the element. */ // Event delegation const list = document.querySelector("#item-list"); list.addEventListener("click", function(event) { // Check if the clicked element is a list item if (event.target.tagName === "LI") { console.log("List item clicked:", event.target.textContent); // Remove the item event.target.remove(); } }); // This is more efficient than adding an event listener to each list item // and works for dynamically added items as well.
Example: Event delegation is a powerful pattern that leverages event bubbling to handle events at a higher level in the DOM. It's especially useful when you have many elements that need the same event handler or when elements are dynamically added to the DOM.

Form Controls

Learn to handle forms, validation, and user input:

// Form submission const form = document.querySelector("#my-form"); form.addEventListener("submit", function(event) { // Prevent default form submission event.preventDefault(); // Get form data const formData = new FormData(form); // Convert to object const formDataObj = {}; for (let [key, value] of formData.entries()) { formDataObj[key] = value; } console.log("Form data:", formDataObj); // Send data to server fetch("/api/submit", { method: "POST", body: formData }) .then(response => response.json()) .then(data => console.log("Server response:", data)) .catch(error => console.error("Error:", error)); });
Note: The FormData interface provides a way to easily construct a set of key/value pairs representing form fields and their values. It's particularly useful for sending form data with fetch.

Form validation:

// HTML5 validation attributes /* */ // JavaScript validation function validateForm(form) { const nameInput = form.querySelector("#name"); const emailInput = form.querySelector("#email"); const passwordInput = form.querySelector("#password"); let isValid = true; // Validate name if (nameInput.value.trim() === "") { showError(nameInput, "Name is required"); isValid = false; } else { clearError(nameInput); } // Validate email const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/; if (!emailRegex.test(emailInput.value)) { showError(emailInput, "Please enter a valid email"); isValid = false; } else { clearError(emailInput); } // Validate password if (passwordInput.value.length < 8) { showError(passwordInput, "Password must be at least 8 characters"); isValid = false; } else { clearError(passwordInput); } return isValid; } function showError(input, message) { const formGroup = input.parentElement; const errorElement = formGroup.querySelector(".error") || document.createElement("div"); errorElement.className = "error"; errorElement.textContent = message; errorElement.style.color = "#ff6b6b"; errorElement.style.fontSize = "0.8rem"; errorElement.style.marginTop = "0.25rem"; if (!formGroup.querySelector(".error")) { formGroup.appendChild(errorElement); } input.style.borderColor = "#ff6b6b"; } function clearError(input) { const formGroup = input.parentElement; const errorElement = formGroup.querySelector(".error"); if (errorElement) { formGroup.removeChild(errorElement); } input.style.borderColor = ""; } // Use the validation function form.addEventListener("submit", function(event) { event.preventDefault(); if (validateForm(this)) { // Form is valid, submit it console.log("Form is valid, submitting..."); // this.submit(); } });

Working with different form controls:

// Text inputs const textInput = document.querySelector("#text-input"); textInput.addEventListener("input", function() { console.log("Text input value:", this.value); }); // Checkboxes const checkbox = document.querySelector("#checkbox"); checkbox.addEventListener("change", function() { console.log("Checkbox checked:", this.checked); }); // Radio buttons const radioButtons = document.querySelectorAll('input[name="radio-group"]'); radioButtons.forEach(radio => { radio.addEventListener("change", function() { if (this.checked) { console.log("Selected radio:", this.value); } }); }); // Select dropdown const select = document.querySelector("#select"); select.addEventListener("change", function() { console.log("Selected option:", this.value); console.log("Selected text:", this.options[this.selectedIndex].text); }); // Multiple select const multiSelect = document.querySelector("#multi-select"); multiSelect.addEventListener("change", function() { const selectedOptions = Array.from(this.selectedOptions).map(option => option.value); console.log("Selected options:", selectedOptions); }); // Textarea const textarea = document.querySelector("#textarea"); textarea.addEventListener("input", function() { console.log("Textarea value:", this.value); });
Example: Form validation can be done both on the client side and server side. Client-side validation provides immediate feedback to users, while server-side validation ensures data integrity and security.
